# HR-ANALYSTICS
An interactive Power BI dashboard analyzing HR data for 1,470 employees. It covers workforce overview, attrition patterns by department, salary slab, job role, age, gender, and experience, plus employee-level satisfaction and performance details. Built with Power Query, DAX, and a Star Schema to support data-driven HR decisions.
# HR Analytics Dashboard | Power BI

## Overview
An interactive Power BI dashboard that analyzes workforce data to understand
employee demographics, attrition patterns, and satisfaction levels.

## Dashboard Pages
1. **Home:** navigation page linking to all sections.
2. **Overview:** headcount (1,470), average tenure (7.0 yrs), gender split,
   and department/job-role breakdown with attrition rates.
3. **Attrition:** 237 employees left (16.1% attrition rate), analyzed by
   department, salary slab, job role, age group, gender, and experience.
4. **Employee:** detailed employee-level table with satisfaction and
   performance indicators.

## Key Insights
- Overall attrition rate is **16.1%**.
- **Sales** has the highest attrition rate (21%), and **Sales Representative** is the highest-risk role (39%).
- Most attrition happens in the **lowest salary slab (up to 5K)**.
- Attrition is highest among employees with **0–1 years of experience**.
- Males represent about **63%** of attrition cases.

## Tools
Power BI, DAX, Power Query, Star Schema
